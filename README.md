# 音乐游戏谱面编辑器

这是一个基于 Godot 游戏引擎开发的音乐游戏谱面编辑器，用于创建和编辑音乐游戏的谱面数据。

## 项目特性

### 已实现功能

- **Meta 编辑**：编辑谱面元数据，包括 BPM 列表、偏移值和时长
- **Notes 编辑**：编辑音符数据，支持多种音符类型
- **判定线管理**：创建、删除、重命名判定线
- **谱面统计**：实时显示谱面物量和动效数量
- **快捷键支持**：Ctrl+S 保存，F11 全屏等

### 待实现功能

- **Effect 编辑**：编辑特效事件
- **Texture 编辑**：编辑纹理资源
- **Shader 编辑**：编辑着色器效果

## 技术栈

- **引擎**：Godot 4.6 (GL Compatibility 模式)
- **语言**：GDScript
- **文件格式**：RWC (JSON 格式)

## 谱面文件格式 (RWC)

### 根级结构

- `BPMList`：BPM 变化列表
- `META`：谱面元数据
- `judgeLineGroup`：判定线分组名称
- `judgeLineList`：判定线详细数据

### 音符类型

- **0**：Hold
- **1**：Tap
- **2**：Drag

### 时间格式

使用节拍格式：`[整数部分, 分子, 分母]`

- 例如：`[0, 0, 1]` 表示第 0 拍
- `[1, 0, 1]` 表示第 1 拍
- `[2, 1, 2]` 表示第 2 拍半

## 使用说明

### 基本操作

1. **打开谱面**：在开始页面选择 .rwc 谱面文件
2. **Meta 编辑**：修改 BPM、偏移和时长
3. **Notes 编辑**：在判定线上添加、删除和调整音符
4. **判定线管理**：创建新判定线，修改判定线名称和分组
5. **保存谱面**：使用 Ctrl+S 或保存按钮保存更改

### 快捷键

- **Ctrl+S**：保存谱面
- **F11**：切换全屏模式
- **上下方向键**：调整节拍细分（仅在 Notes 模式）
- **Ctrl+上下方向键**：调整像素密度（仅在 Notes 模式）
- **Ctrl+F**：修复整数类型并保存
