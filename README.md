# OpenRhyth — 开源节奏游戏谱面编辑器

基于 Godot 4.6 引擎开发的音乐游戏谱面编辑器与游玩平台。提供从谱面创作到 3D 预览、游玩的完整工作流。

## 功能概览

### 谱面编辑

- **Meta 编辑** — 编辑 BPM 列表（支持多段变速）、音频偏移量、音乐时长
- **Notes 编辑** — 在判定线上创建/编辑 Tap、Hold、Drag 三种音符，支持框选、复制粘贴、量化对齐
- **Effect 编辑** — 编辑判定线动效事件（位移 X/Y/Z、旋转 X/Y/Z、透明度、速度、判定线长度、音符透明度），支持瞬时/持续两种模式
- **Texture 编辑** — 为判定线绑定图片或视频贴图，支持自定义显示时段
- **Shader 编辑** — 编辑全局雾效浓度和背景色 RGB 通道变化

### MIDI 辅助采音

- **MIDI 导入** — 选择 MIDI 文件并解析，自动提取 BPM 信息和音符位置
- **多轨道选择** — 支持多轨道 MIDI 文件，可勾选参考轨道（多选）
- **BPM 自动填充** — 一键将 MIDI 中的 tempo 事件写入谱面 BPM 列表
- **参考线显示** — 在 Notes、Effect、Shader 编辑网格中绘制蓝色 (#66ccff) 参考横线
- **Ctrl 吸附** — 按住 Ctrl 时自动吸附到最近的 MIDI 参考节拍位置
- **偏移调节** — 可设置 MIDI 参考线的整体节拍偏移量

### 判定线管理

- 创建/删除/重命名判定线
- 分组管理，支持自定义组序号
- 统计每根判定线的物量和动效数量

### 3D 预览与游玩

- **3D 预览** — 在编辑器内启动 3D 实时预览，支持播放/暂停、进度条拖动
- **游玩模块** — 完整音游体验，包含计分、连击、判定特效、FC/AP 指示器、雾效渲染
- **判定等级** — Perfect1 / Perfect / Good / Miss，支持校准偏移

### 编辑器便利功能

- **复制粘贴** — Notes、Effect、Shader 面板均支持 Ctrl+C / Ctrl+V，粘贴时可指定起始节拍
- **量化** — Ctrl+U 将选中元素对齐到最近网格线，持续类元素的结束时间同步偏移
- **网格调节** — 上下方向键调节节拍细分，Ctrl+上下方向键调节像素密度（设置自动持久化）
- **进度保持** — 切换编辑面板和判定线时自动保持滚动位置，仅返回首页时重置
- **自动保存** — 可配置自动保存间隔，存为 `.autosave.rwc` 不覆盖原文件
- **快捷键自定义** — 所有快捷键均可在设置页面修改
- **偏好持久化** — 节拍细分、网格密度等设置保存到 `settings.json`

## 使用教程

### 快速入门：从零创建第一个谱面

本教程将引导你从空白谱面开始，完成一个包含音符、动效的完整谱面。

---

#### 第 1 步：启动与新建谱面

1. 启动程序，进入首页
2. 点击 **"选择音乐"**，选择一首 mp3/ogg/wav 格式的音乐文件
3. 点击 **"新建谱面"**，选择一个路径并输入文件名（如 `mychart.rwc`），点击保存
4. 可以看到"选择谱面"旁边的文字已经更新为新建的文件路径
5. 点击 **"编辑 RWC"** 进入编辑器

---

#### 第 2 步：设置 Meta（元数据）

进入编辑器后，默认打开 Meta 编辑面板：

1. **自动填充时长**：点击 Meta 面板中音乐时长输入框旁边的 **"自动"** 按钮，自动填入音乐长度
2. **设置 BPM**：在 BPM 列表中默认有一条 120BPM 的条目：
   - 点击选中该条目
   - 在下方的 "BPM=" 输入框中修改数值（如改为 140）
   - 在 "StartTime=" 输入框修改开始节拍，格式为 `[整数, 分子, 分母]`
   - 如需多段变速，点击 **"新建"** 添加更多 BPM 点
3. **使用 MIDI 导入**（可选）：
   - 点击右侧 **"导入 MIDI"** 按钮，选择 .mid 文件
   - 解析成功后，轨道列表会显示所有轨道名称
   - 勾选需要参考的轨道（可多选）
   - 点击 **"应用 BPM"** 将 MIDI 中的 tempo 事件写入 BPM 列表
   - 在下方 **"偏移量（节拍）"** 输入框可调整 MIDI 参考线的整体偏移

---

#### 第 3 步：创建判定线

编辑器左侧为判定线管理面板：

1. 点击 **"新建"** 按钮创建一条新的判定线
2. 选中一条判定线，点击 **"重命名"** 可修改名称和分组
3. 判定线按分组显示（Group），同一组的判定线在游戏中同步运动

---

#### 第 4 步：编辑音符（Notes）

点击顶部 **"Notes"** 按钮进入音符编辑模式：

**界面说明**：
- 横轴为音符的 X 位置（-100 到 100），竖轴为时间（从下往上递增）
- 红色横线为当前参考线（滚动条位置）
- 灰色横线为节拍网格线（实线=整数拍，虚线=细分拍）
- 蓝色横线为 MIDI 参考线（如已导入 MIDI）

**放置音符**：
1. 切换放置模式：Ctrl+1 = Tap，Ctrl+2 = Drag，Ctrl+0 = Hold
2. 在网格中点击放置音符
3. Hold 需要点击两次：第一次设起点，第二次设终点
4. 右键拖动可平移视图，滚轮上下滚动

**编辑音符**：
- **选择**：在浏览模式下点击选中音符；框选（空白处拖动）；按住 Ctrl 多选
- **删除**：选中后按 Delete
- **复制粘贴**：Ctrl+C 复制选中音符，Ctrl+V 粘贴（会弹出对话框输入起始节拍）
- **量化**：选中后按 Ctrl+U，音符自动对齐到最近网格线
- **双击**：打开 JSON 编辑器，可直接修改音符属性
- **按 Ctrl 放置**：自动吸附到最近网格线或 MIDI 参考节拍

**调节视图**：
- ↑/↓：增加/减少节拍细分（如 4 表示 1/4 拍线）
- Ctrl+↑/↓：放大/缩小网格密度
- ←/→：水平滚动

---

#### 第 5 步：编辑动效（Effect）

点击顶部 **"动效"** 按钮进入动效编辑模式：

**动效类型**：moveX/moveY/moveZ（位移）、rotateX/rotateY/rotateZ（旋转）、alpha（透明度）、speed（速度）、length（判定线长度）、notesAlpha（音符透明度）

**放置动效**：
- Ctrl+1：瞬时动效模式（单个事件点）
- Ctrl+0：持续动效模式（包含起止时间）
- Ctrl+Space：浏览模式

**编辑技巧**：
- 选择、复制粘贴、删除、量化等操作与 Notes 面板相同
- 动效值在放置时可查看鼠标悬停提示

---

#### 第 6 步：编辑 Shader（着色器）

点击顶部 **"Shader"** 按钮进入 Shader 编辑模式：

**类型**：Fog（雾效浓度）、BackgroundR/G/B（背景色通道）

操作方式与 Effect 面板一致，用于控制全局视觉效果的变化。

---

#### 第 7 步：绑定贴图（Texture）

点击顶部 **"贴图"** 按钮进入贴图编辑模式：

1. 在左侧判定线树选中要绑定的判定线
2. 点击 **"添加"** 选择图片（png/jpg）或视频（ogv）文件
3. 双击条目可编辑 JSON 属性，包括显示时段（startTime/endTime）

---

#### 第 8 步：3D 预览

1. 编辑过程中随时点击 **"预览"** 按钮进入 3D 场景
2. 按 **Space** 播放/暂停，拖动进度条跳转
3. 按 **ESC** 返回编辑器，滚动位置自动保持

---

#### 第 9 步：保存与游玩

1. **Ctrl+S** 或点击 **"保存"** 按钮保存谱面
2. 返回首页，点击 **"游玩模块"** 进入沉浸式 3D 游玩

---

### 进阶技巧

#### 使用 MIDI 辅助制作完整谱面

1. 准备一个 MIDI 文件（可从 DAW 导出，或网上下载）
2. 在 Meta 页面导入 MIDI，勾选需要的轨道
3. 点击 **"应用 BPM"** 让 BPM 列表与 MIDI 同步
4. 切换到 Notes 编辑面板，可看到蓝色的 MIDI 参考线
5. 按 Ctrl 放置音符时自动吸附到 MIDI 节拍位置
6. 如果参考线与音乐错位，可在 Meta 页面调整偏移量

#### 复制粘贴跨节拍

1. 选中一组音符/动效，Ctrl+C 复制
2. 切换到目标位置，Ctrl+V
3. 在对话框中输入起始节拍（支持小数如 4.5 或带分数如 `4 1/2`）
4. 所有元素会以相对位置关系粘贴到新位置

#### 快速修复问题

- **整数类型错误**：Ctrl+F 可修复谱面中所有整数字段并保存
- **动效格式修复**：在 Effect 面板按 Ctrl+Shift+F 修复格式

## 谱面文件格式 (RWC)

RWC 使用 JSON 格式，核心结构：

| 字段 | 说明 |
|------|------|
| `BPMList` | BPM 变化列表，每项含 `bpm` 和 `startTime` |
| `META` | 谱面元数据（`offset`, `duration`, `notes`） |
| `judgeLineList` | 判定线数组，每条判定线含 `notes`、`eventLayers`、`textures` |

**时间格式**：使用节拍分数表示 `[整数, 分子, 分母]`，例如 `[2, 1, 2]` 表示第 2.5 拍。

**音符类型**：0=Hold, 1=Tap, 2=Drag
