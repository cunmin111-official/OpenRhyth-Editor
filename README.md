# 音乐游戏谱面编辑器

这是一个基于 Godot 游戏引擎开发的音乐游戏谱面编辑器，用于创建和编辑音乐游戏的谱面数据。

## 项目特性

### 已实现功能

- **启动页**：选择 .rwc 谱面文件和对应的音乐文件
- **Meta 编辑**：编辑谱面元数据，包括 BPM 列表、偏移值和时长
- **Notes 编辑**：编辑音符数据，支持 Tap/Hold/Drag 三种音符类型
- **Effect 编辑**：编辑判定线动效事件（位移、旋转、透明度、速度等）
- **Texture 编辑**：为判定线绑定图片或视频贴图
- **Shader 编辑**：编辑全局雾效和背景色变化
- **判定线管理**：创建、删除、重命名判定线及分组
- **谱面统计**：实时显示谱面物量和动效数量
- **3D 预览**：在 3D 空间中实时预览谱面播放效果
- **游玩模块**：沉浸式 3D 谱面播放，含计分、连击、雾效渲染
- **输入调试**：游玩场景实时显示按键和触摸数量统计
- **全局 F11 全屏切换**：所有场景通用

## 谱面文件格式 (RWC)

### 根级结构

- `BPMList`：BPM 变化列表
- `META`：谱面元数据
- `judgeLineGroup`：判定线分组名称
- `judgeLineList`：判定线详细数据

### 音符类型

- **0**：Hold
- **1**：Tap
- **2**：Drag

### 时间格式

使用节拍格式：`[整数部分, 分子, 分母]`

- 例如：`[0, 0, 1]` 表示第 0 拍
- `[1, 0, 1]` 表示第 1 拍
- `[2, 1, 2]` 表示第 2 拍半

## 使用说明

### 基本操作

1. **打开谱面**：在开始页面选择 .rwc 谱面文件和音乐文件
2. **Meta 编辑**：修改 BPM、偏移和时长
3. **Notes 编辑**：在判定线上添加、删除和调整音符
4. **Effect 编辑**：编辑判定线动效事件
5. **判定线管理**：创建新判定线，修改判定线名称和分组
6. **保存谱面**：使用 Ctrl+S 或保存按钮保存更改
7. **3D 预览**：在编辑器中点击预览按钮查看 3D 效果
8. **游玩模块**：在启动页点击"游玩模块"直接播放谱面

### 快捷键

| 快捷键 | 功能 | 适用场景 |
|--------|------|---------|
| **F11** | 切换全屏模式 | 全局 |
| **ESC** | 返回上一场景 | 预览/游玩 |
| **Ctrl+S** | 保存谱面 | 编辑器 |
| **Space** | 开始/停止预览播放 | 编辑器/预览 |
| **上下方向键** | 调整节拍细分 | 编辑器 (Notes/Effect/Shader 模式) |
| **Ctrl+上下方向键** | 调整像素密度 | 编辑器 (Notes/Effect/Shader 模式) |
| **Ctrl+F** | 修复整数类型并保存 | 编辑器 |

## 开发说明

### 编辑器模式

- **Meta 模式**：编辑谱面元数据
- **Note 模式**：编辑音符数据
- **Effect 模式**：编辑动效事件
- **Texture 模式**：编辑纹理
- **Shader 模式**：编辑着色器

### 场景跳转关系

```
start_scene.tscn  ──►  editor_main.tscn  ──►  preview_page.tscn
                  ──►  play_page.tscn
```

### 项目配置

- 分辨率：1920x1080
- 渲染器：GL Compatibility
- 窗口模式：自适应缩放 (canvas_items)

## 注意事项

- 谱面文件使用 JSON 格式存储，扩展名为 .rwc，详情参考谱面文件规范。
- 游玩模块自动从开头播放谱面，ESC 或返回按钮回到主菜单。
